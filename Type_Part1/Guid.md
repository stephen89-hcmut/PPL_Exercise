# Type_Part1 Guide

## Student workflow

1. Tạo môi trường `.venv` và cài dependency theo [requirements.txt](../requirements.txt).
2. Mở một thư mục `exercise_*` và chỉ sửa `solution.py`.
3. Chạy `main.py` để xem test và lý do FAIL.
4. Chạy `main.py --answer` để so sánh với lời giải tham chiếu.
5. Chạy `Type_Part1/run_all.py --answer` để xác nhận toàn bộ reference tests.

Không cần ANTLR cho nhóm này vì đề cung cấp AST trực tiếp. Nhóm gồm năm câu:
ba câu từ PDF Type Programming Code 1 và hai câu từ PDF Type Programming 2.
