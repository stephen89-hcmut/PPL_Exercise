# SEQUENCE

Sáu bài tập được tạo từ PDF `[CC03] Sequence Programming Code`:

1. `visitIntLiteral`
2. `visitFloatLiteral`
3. `visitBinExpr` cho toán tử typed integer/float
4. `visitId`
5. `visitBinExpr` cho mixed numeric types và relational operators
6. `visitVarDecl`

Mỗi bài có `description.md`, `solution.py`, `answer.py` và `main.py`.
Sinh viên sửa `solution.py`; `answer.py` là reference answer.

## Run

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe SEQUENCE\run_all.py
.\.venv\Scripts\python.exe SEQUENCE\run_all.py --answer
```

Linux/macOS:

```bash
.venv/bin/python SEQUENCE/run_all.py
.venv/bin/python SEQUENCE/run_all.py --answer
```
